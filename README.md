# Ismail Anajar — Portfolio

Personal portfolio of **Ismail Anajar**, Full-Stack Developer from Casablanca, Morocco.
Frontend specialization in **React & Next.js**, backend with **Node.js & NestJS**.

## Stack

- Pure HTML / CSS / JavaScript (no framework, 56KB core)
- Neo-brutalist style: `#234df1` (primary) + `#FACC15` (secondary)
- Space Grotesk + Inter + Bricolage Grotesque

## Structure

```
├── index.html      # whole one-page site
├── styles.css      # theme + responsive
├── script.js       # nav, lightbox, reveal, back-to-top
├── assets/         # profile photo, project screenshots, og-image
├── sitemap.xml     # SEO
├── robots.txt      # SEO
└── llms.txt        # summary for AI models
```

## Run locally

Just open `index.html`, or:

```bash
npx serve .
```

## Deploy (Vercel)

```bash
vercel
```

Then update the domain in: `index.html` (canonical + og tags), `sitemap.xml`, `robots.txt`.
